# ⚡ Gemma Open-Weight Hackathon Web App

An interactive web application built with Streamlit that leverages Google's open-weight model (`gemma-4-26b-a4b-it`) via the `google-genai` SDK.

## 🚀 Features
- **Open-Source AI Integration:** Uses Google's open-weight Gemma 4 model.
- **Interactive UI:** Web interface created using Streamlit.
- **Secure Configuration:** Key management handled via environment variables / Streamlit Secrets.

## 🛠️ Tech Stack
- **Language:** Python
- **Frontend / Web:** Streamlit
- **AI Model:** Gemma 4 (`gemma-4-26b-a4b-it`)
- **SDK:** `google-genai`
